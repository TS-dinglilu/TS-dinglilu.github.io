板块一 · 四旋翼控制与安全（本周主题：在线自适应）

① OA-MPPI：给 MPPI 装上「遮挡感知」，真机实时闭环

MPPI避障🔥 9/23上新arXiv:2609.28709 · 2026-09-23

伯克利团队（Palladino、Yang、Zhang、Mueller）9 月 23 日提交的 OA-MPPI：杂乱且部分未知环境中的四旋翼飞行，不仅要避开已观测到的障碍，还要对传感器不可见的遮挡区域做推理。每个规划步从在线占据栅格中提取 3D 遮挡边界，据此建模「隐藏智能体可能在预测时域内到达的区域」，在基于非线性四旋翼动力学、计入单旋翼推力上限的 MPPI rollout 中惩罚进入这些扩张区域的轨迹。仿真与硬件飞行实验双验证，完整管线在机载实时运行——相对基线 MPPI，与遮挡边界的净距显著增大，并成功规避了从遮挡区冲出的智能体。对飞控仿真的启示：遮挡建模是把「感知不确定性」转成「控制代价」的干净接口，与你的 RViz/Gazebo 遮挡仿真课题可以无缝衔接。

自适应控制🔧 在线辨识arXiv:2609.03351 · 2026-09-03

Tam W. Nguyen 的 Taylor 主动预测代价控制（PCAC）+ 在线重力配平自适应：在标称悬停附近做非线性动力学的一、二、三阶 Taylor 展开，构成稀疏采样数据字典，用变遗忘因子递推最小二乘逐行辨识；每步把辨识出的预测器线性化在当前状态、Jacobian 在预测时域内固定。亮点是用辨识出的垂向动力学同时估计飞行器质量与重力配平输入，彻底摆脱固定名义重力补偿——仿真中载荷突变 + 激进螺旋跟踪场景下，高阶预测器显著改善预测与跟踪精度。对做载荷变化/参数摄动仿真课题的读者，这是「RAC + 系统辨识」路线的最新模板。

仿真框架🎮 动力学扮演arXiv:2609.06520 · 2026-09-06

动态系统仿真（Dynamic System Emulation）：让搭载两轴云台的多旋翼模拟固定翼的飞行动力学。用动态反馈线性化推导两平台间的状态-输入映射，规避固定翼最小空速、非完整约束等气动限制；在代表性固定翼机动上评估，标称条件下高保真复现。当前为仿真验证，但给出了面向飞行员训练、自主性研究与控制器基准测试的硬件化路径——「一台多旋翼当多台飞行器用」，对实验室没有固定翼平台的情况是低成本的替代思路。

板块二 · LLM/VLA 与无人机控制

① DroneCATS：把多模态大模型直接扔进无人机控制环，结论很扎心

MLLM基准🔥 14人团队arXiv:2609.01404 · 2026-09-01

DroneCATS-Agent 架构 + DroneCATS 基准：把多模态大模型（MLLM）作为可替换组件直接放进无人机控制环，整个动作空间只靠 prompt 声明，不做微调、不用 function-calling schema。四项核心能力评测：接近可见目标、跟踪移动目标、搜索初始视野外目标、指挥多机编队，参评模型从前沿闭源到 2B 参数小模型。核心悖论：「失败的不是飞行」——小开源模型往往比前沿模型更可靠地飞进成功半径，却因「过早宣布到达」或「到不了位不宣布」输掉整段任务；多机指挥进一步放大了这个鸿沟。结论：空间感知在线，行动协议不在线；可部署的边缘模型与前沿模型的差距不在导航，而在「坚持既定协议并发出正确终止动作」的纪律性。

LLM集群🌐 WoWMoM 2026arXiv:2605.03788

Say the Mission, Execute the Swarm（WoWMoM 2026 录用）：面向「说一句话、执行一群机」的智能体增强 LLM 集群管理架构。两个关键创新：① 用 LLM 推理 + function-calling 协调无人机动作，不依赖任务初始化时的静态代码生成；② 通过 MCP 协议 + W3C Web of Things 标准把每架无人机建模为 WoT Thing，实现 LLM 智能体与物理系统的标准化双向通信，并以「推理-执行-监控」闭环 + 护栏 prompt 保障安全。评测接 ArduPilot 真实飞控与物理仿真，对比 GPT v5.2、DeepSeek v3.2、GLM v4.7、Grok v4.1 Fast、Claude Haiku v4.5、Qwen 3 8B 六个模型在区域覆盖、编队控制、智能灌溉三类任务上的表现：外部知识注入通常有帮助但不稳定；小模型任务表现普遍弱于大模型；任务成功率与 token 消耗（运营成本）无明确相关。

持续定位🗺️ 21架次验证arXiv:2604.09038 v2 · 2026-09-03

面向终身飞行自主性的几何记忆管理（北航孟智宇团队等，v2 更新于 9 月 3 日）：把航拍视觉位置识别（VPR）建模为「基于任务的域增量学习」问题——卫星参考图训练初始模型并构建静态样本记忆，机载观测进入有界回放缓冲区，通过 DBS-Hybrid 准则（原型多样性裁剪 + 代表性优先覆盖）管理回放，对抗连续任务带来的视觉分布漂移与灾难性遗忘。在 21 个可见光与红外无人机任务上评估：主要任务顺序下，平均最终精度、泛化与知识保持三项指标较随机基线分别提升 5.06、5.32、6.33 个百分点，后向迁移从 -6.41% 翻正到 1.07%。长期驻留、跨季节重飞的场景（巡检、测绘）里这是很实用的模块，定位与 SLAM 方向的同学可精读。

板块三 · 集群协同与组网

① 从视觉跟随编队到自组织网络：本周两篇「去 GPS 化」路线

视觉编队📷 RGB-D跟随arXiv:2609.01420 · 2026-09-01

GPS 退化环境下的视觉 Leader-Follower 编队：跟随机用前视 RGB-D 相机实时检测、跟踪并定位领航机——轻量 YOLO 检测器输出边界框，经针孔相机模型与深度信息融合估计领航机相对位姿，直接馈入跟随位置控制器，并可在 GPS 或外部定位失效时作为备份。框架以 ROS 节点实现，在基于 XTDrone 的多机物理仿真中评估（含传感器噪声与通信中断）。结论：可在合理计算开销下维持稳定编队——XTDrone + YOLO + 位姿融合这条技术栈对硕士课题的可复现性极好，与 PX4/SITL 仿真平台可以拼成一套完整实验。

📚 本期方法论小结
ℹ️ 三条可迁移线索（写给飞控仿真课题）

① 遮挡即代价：OA-MPPI 把「看不见的区域」编码成随时间扩张的惩罚区，直接嵌入采样式 MPC rollout——在 Gazebo/PX4 环境里复现一个二维最小版，就是一篇现成的课程项目。② 在线辨识替代离线标定：Taylor-PCAC 用递推最小二乘同时估质量与重力配平，载荷突变场景的跟踪精度提升有清晰的消融故事可讲，与你的 Simulink 参数辨识模块天然互补。③ 行动协议评测：DroneCATS 证明 LLM 控制环的失败集中在「终止动作纪律」，做 VLA/LLM 相关课题时把「宣布到达」设计成显式可验证的协议状态，评测立刻严谨一档。
