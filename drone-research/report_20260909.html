✈️ 飞行控制方向

1. 泰勒展开驱动的预测代价自适应控制（PCAC）+ 在线重力配平
📌 arXiv: 2609.03351📅 2026-09-03📂 eess.SY

Taylor-Informed Predictive Cost Adaptive Control for Quadrotors with Online Gravity-Trim Adaptation（Tam W. Nguyen）。对非线性动力学在标称悬停点做一/二/三阶泰勒展开，构造稀疏采样数据字典，用变速率遗忘的行递推最小二乘辨识；每步在当前状态线性化预测器并在预测时域内固定雅可比。辨识出的垂向动力学同时估计机体质量与重力配平输入，消除固定标称重力补偿。突变载荷与激进螺旋线跟踪上，高阶预测器显著改善预测与跟踪性能。

2. 执行器动力学感知的四旋翼端到端 DRL（Simulink Level-2 S-Function）
📌 arXiv: 2607.25985📅 2026-07，本月持续被引📂 cs.RO

Physics-Aware End-to-End Deep RL for Quadcopter Control with Actuator Dynamics。四旋翼是典型欠驱动系统（4 输入支配 6 自由度）。智能体直接输出底层机体输入（总推力与三轴力矩 T, τx, τy, τz），在高保真 Simulink 环境闭环。仿真器集成 12 状态刚体模型（MATLAB Level-2 S-Function），含基于推力/阻力系数矩阵 Moore-Penrose 伪逆的 Action2RPM 分配、每电机一阶执行器动力学（Tm = 0.076 s）与旋翼陀螺耦合。奖励由指数位置势阱、姿态惩罚与速度二次代价构成，两阶段评估（S1 仅推力悬停；S2 带俯仰力矩与目标平移）。

结论：SAC 与 TD3 在稳定性与探索效率上最优，PPO 样本效率偏低；核心贡献是建模执行器滞后与气动力矩对底层控制稳定性至关重要。

🛡️ 安全强化学习方向

3. 降低保守性的安全 RL：无人机穿越峡谷真机验证
📌 arXiv: 2608.26852📅 2026-08-27📂 eess.SY

Towards Safe RL with Reduced Conservativeness: A Case Study on Drone Flight Control（Hadjiloizou, Welle, Yin, Kragic）。用在线采集数据精化扰动模型以降低形式化方法的保守性，并用计算高效的 zonotopic 可达性分析评估学习型控制器安全性，支持实时实现。在真实无人机穿越峡谷飞行中验证——受未知外部扰动时，框架需在线学习扰动并相应调整安全保证。结果表明可在不牺牲安全性的前提下实现更少约束的在线训练。

4. 信息引导安全 RL 实现 sUAS 自主气体源定位（RCBF 兜底）
📌 arXiv: 2609.05569📅 2026-09-04📂 cs.RO（投 IEEE CDC 2026）

Information-Guided Safe RL for Autonomous Gas Source Localization using sUAS（Giri, Zhao, Huynh, Chen）。湍流边界层中浓度场高度间歇，经典梯度导航失效。在自建 GPU 加速 3D 仿真（欧拉风场 + 拉格朗日烟团扩散）中，作者发现确定性信息寻优规划器存在 Gramian 偏差——基于有缺陷的早期估计贪婪行动，使估计器丧失空间多样性。为此把经验可观测 Gramian（EMGR）规划器与学习式 SAC 探索策略结合，元监督器用 KL 散度监测估计器可靠性、动态混合利用与探索，并由鲁棒控制屏障函数（RCBF）严格保障安全。

结果：复杂移动源定位成功率接近 80%，远超经典基线的约 30%，且零安全违规。

6. AgilePE：自博弈 RL 无人机追逃（CTBR 端到端 + 双机零样本真机）
📌 智源社区论文库📅 2026-08-14📂 cs.RO

AgilePE: Autonomous UAV Pursuit-Evasion via Self-Play RL（唐文浩、高飞、于超等）。策略直接把机载观测映射为集体推力与机体角速率（CTBR）指令，无需中间轨迹规划器或航点控制器。训练采用优先级虚构自博弈（PFSP）并构建多样化对手策略池以抑制策略振荡；部署侧设计硬件对齐仿真流水线，精确建模执行器响应、通信延迟与域随机化。策略无需任何任务特定调优即可零样本迁移真机，并首次实现双机交互式、零样本真实场景部署。

🗺️ 多机协同

7. TriSAR：5 机灾害响应任务协调与避碰（2×2 因子设计）
📌 arXiv: 2609.01731📅 2026-09-01📂 cs.RO

TriSAR: Task Coordination and Collision Avoidance for Aerial Robot Teams in Disaster Response。在 Gazebo 地震损毁城市场景中评估 5 机系统，采用 2×2 因子设计：两种任务分配（遗传算法 vs. 贪婪）× 反应式避碰开/关，每种配置 30 个随机回合，场景固定为 5 机 8 目标。结果：贪婪分配下启用排斥项完全消除碰撞阈值违规（Mann-Whitney U = 885, p = 4.03×10⁻¹²）；GA 分配下同样确认。任务效率上，启用排斥时 GA 相对贪婪无可检测优势，关闭排斥时 GA 显著更优（Welch 检验 |g| 在 0.92–1.76）——结论诚实且有统计支撑。

AgilePE 引发的争论：端到端 RL 直出 CTBR 是否该取代分层控制？
智源社区论文库2026-08-14

AgilePE 把机载观测直接映射为 CTBR 指令，跳过轨迹规划器与航点控制器。争议焦点：这种端到端在敏捷对抗场景优势明显（零样本真机、双机交互），但可解释性与安全认证不如分层方案。折中观点是保留底层控制器做安全兜底（RCBF/CBF）、上层用 RL 出指令——也正是 arXiv:2609.05569 与 2608.26852 的选择。📎 查看原文

✍️ 写作参考建议

1. 把"执行器动力学"写进贡献点，是低成本高收益的差异化

arXiv:2607.25985 与 AgilePE 都把"精确建模执行器响应/电机滞后"作为明确贡献。若你的 Simulink 模型目前用理想推力模型，可考虑补一节：一阶电机滞后（Tm 约 0.076 s）+ Moore-Penrose 伪逆分配 + 旋翼陀螺耦合。这在审稿人眼里是"考虑工程实际"的直接证据，实现成本主要在改 S-Function，无需新的理论推导。

2. 安全 RL：用"降低保守性"切入，比单纯"加一个 CBF"更新

本期两篇安全 RL 选择同一叙事：形式化方法太保守 → 用在线数据精化扰动/误差模型 → 在保持安全前提下恢复探索能力。写作可直接复用三段式：现有安全过滤器保守 → 本文用 XX 在线收紧界 → 实验证明安全违规为 0 且性能提升 XX%。

3. 奖励函数写"三层蛋糕法则"，并主动暴露一个失败案例

把奖励拆成基础层（任务目标）+ 引导层（阶段性引导）+ 修饰层（平滑/能耗惩罚）三层，比堆一串加权项清晰得多。更重要的是主动写出一个失败的奖励设计及其现象——审稿人普遍认为这类负结果比又一组成功曲线更能体现对问题的理解。
