2. 物理感知端到端 DRL 含执行器动力学（MATLAB Level-2 S-Function + Simulink 闭环）
📌 arXiv: 2607.25985📅 2026-07-28📂 cs.RO

Physics-Aware End-to-End Deep Reinforcement Learning for Quadcopter Control with Actuator Dynamics（Ya-Chia Shen, Woei-Leong Chan）。四旋翼是典型欠驱动系统（4 输入支配 6 自由度）。智能体直接输出底层机体输入（总推力与三轴力矩 T, τx, τy, τz），在高保真 Simulink 环境闭环。仿真器集成 12 状态刚体模型（MATLAB Level-2 S-Function），含基于推力/阻力系数矩阵 Moore-Penrose 伪逆的 Action2RPM 分配、每电机一阶执行器动力学（Tm = 0.076 s）与旋翼陀螺耦合。奖励由指数位置势阱、姿态惩罚与速度二次代价构成，两阶段评估（S1 仅推力悬停；S2 带俯仰力矩与目标平移）。

结论：SAC 与 TD3 在稳定性与探索效率上最优，PPO 样本效率偏低；核心贡献是建模执行器滞后与气动力矩对底层控制稳定性至关重要，并给出可复现的四旋翼 DRL 基准。该文与你的「Simulink + Python 强化学习」路线几乎同构，中文解读见 alphaXiv 与 ibbac 镜像。

✍️ 写作参考与开题建议

1. 把「执行器动力学」写进贡献点，是低成本高收益的差异化

2607.25985 与 DRL-DFCM（TTE 2026）都把「精确建模执行器响应/电机滞后」作为明确贡献。若你的 Simulink 模型目前用理想推力模型，可考虑补一节：一阶电机滞后（Tm 约 0.076 s）+ Moore-Penrose 伪逆分配 + 旋翼陀螺耦合。这在审稿人眼里是「考虑工程实际」的直接证据，实现成本主要在改 S-Function，无需新理论推导。

2. 课程学习提样本效率，直击 RL 飞控训练痛点

2501.18490 用三阶段课程（固定初态悬停 → 随机化初位置/姿态/速度 → 完整随机）将 PPO 样本效率与收敛时间显著改善。你的开题若涉及「训练慢/难收敛」，可直接沿用该叙事：把复杂任务渐进分解 + 加性奖励纳入暂态与稳态指标，比单阶段端到端更易说服评审。

3. 安全约束「前移」：用 CBF/RCBF 做底层兜底，RL 出上层指令

多四旋翼 H∞ 论文（中山大学）与重载 eVTOL 的 DFCM 都采用同一思路：规划/控制层显式纳入执行器与安全边界，而非事后滤波。写作可复用三段式：现有安全过滤器保守 → 本文用 XX 在线收紧界 → 实验证明安全违规为 0 且性能提升 XX%。AC-MPC 更给出「可微 MPC 作 Actor 末层」的优雅实现，代码已开源可作 baseline 对标。

4. 奖励函数写「三层蛋糕法则」，并主动暴露一个失败案例

把奖励拆成基础层（任务目标）+ 引导层（阶段性引导）+ 修饰层（平滑/能耗惩罚）三层，比堆一串加权项清晰得多。更重要的是主动写出一个失败的奖励设计及其现象——审稿人普遍认为这类负结果比又一组成功曲线更能体现对问题的理解。可结合 MATLAB/Simulink 实战中「AGV 躺平角落」类反例。
