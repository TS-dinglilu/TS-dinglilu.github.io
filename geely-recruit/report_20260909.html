💡 重点提示：航空航天类是你的差异化机会

控制律算法岗、导航算法岗、螺旋桨结构动力学岗与你的四旋翼飞行控制与仿真方向高度同构——飞控本质就是姿态/位置回路控制律设计 + 导航滤波 + 结构动力学建模。这是吉利体系内竞争最小、匹配度最高的赛道，车辆工程背景候选人普遍不具备飞控经验，建议占掉3次机会中的1次。

① 控制律算法岗（航空航天类）
杭州 / 上海硕士 · 面议最高匹配
四旋翼飞控（姿态/位置回路、PID/LQR/ADRC、卡尔曼滤波）与无人机控制律数学本质相同，是唯一能碾压车辆工程竞争者的赛道。
② 智能仿真技术开发岗（整车研发类）
杭州滨江硕士 · 面议高匹配
Simulink / Gazebo / ROS 仿真经验可直接迁移，整车研发以硕士为主，是最稳的主投方向。
③ 底盘域控系统集成算法岗
杭州 / 上海硕博 · 面议中高匹配
底盘域控 = "被控对象+执行器+控制器"集成，与飞控系统集成逻辑一致。需补C/C++ 与 Simulink代码生成。
④ 新能源电源BMS / 热力学开发岗
杭州 / 宁波 / 西安硕士 · 面议中匹配
若课题涉及电池建模、热分析、功耗优化，这条线值得投。
⚠️ 三个必须补的短板

① 编程：IT/互联网类岗普遍考算法与代码，补 Python + C++，能手写基本数据结构与数值计算；② 汽车领域知识：至少搞懂整车架构、三电、底盘基本术语；③ 英语：部分岗位笔试含专业英语翻译。
