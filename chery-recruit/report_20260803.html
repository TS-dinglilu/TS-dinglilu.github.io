🎯面试经验分享板块 05

面试流程

校招流程：网申投递 → 简历筛选 → 笔试（行测+性格测试+专业知识） → 技术面（1-2轮） → HR面 → offer发放。整个流程约2-4周。

社招流程：简历投递 → 电话初筛 → 技术面（部门主管） → HR面 → 谈薪 → offer。部分岗位需要笔试或实操考核。

面试经验精选

底盘工程师面试：技术面根据简历项目经历提问，底盘和车身方向轮流面。项目经历适合底盘的会被重点问底盘相关问题。底盘工作强度较大但技术积累扎实。

🏢工作环境与企业文化板块 06
